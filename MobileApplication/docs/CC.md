\# Cloud Computing – Projektbeschreibung



\## Projektübersicht

Dieses Projekt implementiert eine cloudbasierte Anwendung mit einem zentralen Backend und mehreren Clients.



\## Architektur

\- Backend: Node.js REST API (`/server`)

\- Web Client: Astro (`/web`)

\- Mobile Client: Flutter (`/MobileApplication/bachelorhilfe`)



\## Cloud-Aspekte

\- REST-basierte Client–Server-Kommunikation

\- Trennung von Frontend und Backend

\- Skalierbare Architektur

\- Nutzung von SSG, SSR und SPA im Web-Client



\## Abgrenzung

Die Mobile-App wird im Kurs \*Mobile Anwendungen\* bewertet und ist nicht Teil der Cloud-Implementierung.
